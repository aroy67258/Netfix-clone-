# Netflix Clone 🎬

A responsive Netflix Clone built using modern web technologies. This project recreates the core UI and browsing experience of Netflix, including movie banners, categories, and responsive design.

## 🚀 Features

- Responsive Netflix-style UI
- Movie and TV show sections
- Banner with featured content
- Hover effects and smooth transitions
- Clean and modern design
- Mobile-friendly layout

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
- React.js
- Tailwind CSS

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/aroy67258/Netfix-clone-.git
```

Go to the project directory:

```bash
cd Netfix-clone-
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm start
```
